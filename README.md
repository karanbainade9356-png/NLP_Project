Trustworthy Multilingual Natural Language Processing using Large Language Models and Agentic AI
Description:
Develop intelligent NLP systems capable of understanding, analyzing, and generating multilingual text, particularly focusing on low-resource languages. The projects may explore applications such as healthcare communication, educational assistants, sentiment and emotion analysis, retrieval-augmented generation (RAG), and improving reliability and explainability of Large Language Models.
Expected outcomes:
1. Multilingual and low-resource NLP models
2. LLM-based applications
3. RAG-based knowledge systems
4. Emotion and sentiment analysis
5. Explainable and trustworthy AI sol
